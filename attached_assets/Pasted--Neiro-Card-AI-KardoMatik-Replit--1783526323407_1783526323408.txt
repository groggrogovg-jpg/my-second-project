Задача 5: Восстановление пароля через email
Требуемое поведение:

На странице входа (/login) добавить ссылку «Забыли пароль?».

При клике открывается страница (или модальное окно) с полем для ввода email и кнопкой «Отправить ссылку для сброса».

Система проверяет, существует ли пользователь с таким email. Если да:

Генерируется уникальный токен с ограниченным сроком действия (1 час).

Токен и email сохраняются в таблицу password_resets (поля: email, token, expires_at).

На указанный email отправляется письмо со ссылкой для сброса пароля: https://ваш-сайт/reset-password?token=....

Пользователю показывается сообщение: «Ссылка для сброса пароля отправлена на ваш email (если он зарегистрирован)».

При переходе по ссылке открывается страница с формой для ввода нового пароля (и подтверждения).

После отправки формы:

Проверяется токен (существует, не истёк).

Пароль хешируется (bcrypt) и обновляется в записи пользователя.

Токен удаляется из таблицы.

Пользователь перенаправляется на страницу входа с сообщением «Пароль успешно изменён».

Техническая реализация:

Создать таблицу password_resets (если нет) с полями: id, email, token, expires_at.

API-маршруты:

POST /api/auth/forgot-password — принимает { email }, генерирует токен, сохраняет, отправляет письмо.

POST /api/auth/reset-password — принимает { token, newPassword }, проверяет токен, обновляет пароль.

Для отправки писем использовать Resend (или Nodemailer). Если переменные окружения для почты не заданы, выводить ссылку в консоль для тестирования.

Фронтенд: создать страницы /forgot-password и /reset-password (или модальные окна).

После успешного сброса показывать уведомление и редирект на /login.

Безопасность:

Токен генерировать через crypto.randomBytes(32).

Срок действия — 1 час.

При успешном сбросе токен удаляется.

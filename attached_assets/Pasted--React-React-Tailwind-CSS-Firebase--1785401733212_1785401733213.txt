Ты — разработчик React-приложения «КардоМатик». Стек: React + Tailwind CSS + Firebase (или ваш бэкенд).

В приложении уже есть:
- Две модели ИИ: Nano Banana 2 и Nano Banana Pro.
- Тарифные пакеты на 30 дней с карточками для каждой модели.
- Редактор карточек, где можно удалять фон, заменять фон и редактировать изображение.
- Личный кабинет, отображающий балансы карточек по моделям.

Сейчас в редакторе не работает списание «звёзд» (баллов) за использование дополнительных функций (удаление фона, замена фона, редактирование). Нужно реализовать систему звёзд, которая начисляется при покупке любого тарифного пакета и расходуется при использовании этих функций.

## Задача

### 1. Добавить поле «звёзды» в структуру пользователя

В документе пользователя (или в объекте подписки) добавить поле `stars`, которое хранит количество доступных звёзд. Оно должно быть общим для обеих моделей (единый баланс).

Структура пользователя (дополнить):
{
subscriptions: {
nanoBanana2: { ... },
nanoBananaPro: { ... }
},
stars: number, // общий баланс звёзд
starsExpiry: timestamp // дата истечения звёзд (опционально, если они должны сгорать)
}

text

### 2. На странице тарифов (/pricing)

Каждый пакет (для обеих моделей) должен включать определённое количество звёзд. Например:
- 5 карточек → 5 звёзд
- 10 карточек → 10 звёзд
- 50 карточек → 50 звёзд
- 100 карточек → 100 звёзд

(Можно сделать настраиваемым, но пока такие значения.)

При покупке пакета:
- Если у пользователя уже есть звёзды (от предыдущих покупок), они должны суммироваться с новыми (не сгорать, если не истек срок). Но если звёзды имеют срок действия (например, также 30 дней), то при покупке нового пакета старый остаток звёзд заменяется новым? Или суммируется? Судя по логике карточек – они заменяются. Для звёзд лучше сделать так: при покупке нового пакета звёзды добавляются к текущему балансу (суммируются), а срок действия устанавливается на 30 дней от даты последней покупки (или если срок истёк, то баланс обнуляется и начинается новый). Упростим: звёзды начисляются и действуют в течение 30 дней с момента покупки. Если звёзды не использованы, они сгорают через 30 дней.

Но в задаче чётко не сказано про срок, поэтому предлагаю: звёзды начисляются при покупке и не сгорают (бессрочные) – это проще. Однако если у нас пакеты на 30 дней, логично, чтобы звёзды тоже были ограничены сроком. Я предлагаю в промте указать, что звёзды действуют 30 дней и обнуляются по истечении срока, аналогично карточкам. Но можно и оставить бессрочными, если пользователь их накопил.

Напишу вариант с бессрочными звёздами (без срока), чтобы не усложнять. Если нужно, можно добавить срок.

### 3. Отображение звёзд в личном кабинете (/profile)

В профиле добавить блок: «Доступно звёзд: X» (общий баланс). Также можно отображать, сколько звёзд было получено в текущем пакете (но это опционально).

### 4. В редакторе карточек

В редакторе есть кнопки/действия:
- Удалить фон
- Заменить фон
- Редактировать (например, цветокоррекция)

Каждое действие должно списывать 1 звезду (или разное количество, но пока по 1).

Перед выполнением действия проверять:
- Если stars >= 1, то списываем 1 звезду и выполняем действие.
- Если stars < 1, показываем сообщение: «Недостаточно звёзд. Купите тариф, чтобы пополнить баланс.» и перенаправляем на страницу тарифов.

При успешном списании обновить состояние звезд в UI (уменьшить на 1) и показать уведомление «Звезда списана».

### 5. Интеграция с покупкой

При успешной оплате любого пакета (для любой модели) обновить поле stars у пользователя: stars += количество звёзд из пакета.

### 6. Обнуление звёзд (опционально)

Если звёзды должны сгорать через 30 дней, то добавить поле starsExpiry. При покупке устанавливать starsExpiry = now + 30 дней. При каждом действии проверять, не истек ли срок. Если истек – обнулить stars и starsExpiry и показать сообщение.

Упростим: звёзды бессрочные. Это проще для пользователя и для реализации.

## Технические требования

1. В базе данных добавить поле stars (число) и, если нужно, starsExpiry.
2. На странице тарифов в каждом пакете указать количество звёзд (например, иконкой звезды и числом).
3. В личном кабинете отображать текущее количество звезд.
4. В редакторе реализовать проверку и списание при каждом использовании функций.
5. При покупке любого пакета начислять звёзды (суммировать с текущим балансом).
6. Все изменения должны быть согласованы с остальным дизайном (фиолетово-синий градиент).

### Задача

Добавить на сайт переключатель тем (светлая / тёмная). Переключатель должен быть размещён в шапке (навигационной панели) сайта и работать на всех страницах.

### Требования к функциональности

1. **Переключатель**:
   - Кнопка-переключатель (toggle) или иконка (🌙 / ☀️) в правой части шапки (рядом с другими кнопками, например, «Тарифы», «Вход»).
   - При клике тема меняется на противоположную (светлая ↔ тёмная).
   - Иконка переключателя должна меняться в зависимости от текущей темы (солнышко для светлой, луна для тёмной).

2. **Применение темы**:
   - Стилизация осуществляется через CSS-классы или CSS-переменные (`--bg-color`, `--text-color`, `--card-bg`, `--border-color` и т.д.).
   - При переключении добавлять/удалять класс (например, `.dark-theme` или `[data-theme="dark"]`) на корневом элементе (`<html>` или `<body>`).
   - Все компоненты должны реагировать на смену темы без перезагрузки страницы.

3. **Сохранение выбора**:
   - При переключении темы сохранять её в `localStorage` под ключом `theme` (значения: `'light'` или `'dark'`).
   - При загрузке приложения проверять сохранённую тему и применять её.
   - Если тема не сохранена, использовать светлую по умолчанию.

4. **Адаптивность**:
   - Переключатель должен корректно отображаться на мобильных устройствах (в мобильном меню).

5. **Дизайн**:
   - Подобрать цвета для тёмной темы: тёмный фон (например, `#1a1a2e` или `#121212`), светлый текст (`#e0e0e0`), карточки с тёмным фоном (`#2d2d3f`), акцентные цвета оставить теми же, что и в светлой теме (например, синий), но сделать их немного ярче.
   - Переключатель должен быть стилизован в едином стиле с сайтом.

### Что нужно сделать

1. Найти компонент шапки (навигации) в проекте (скорее всего, `Header.js`, `Navbar.js` или `components/Navigation.js`).
2. Добавить в него кнопку-переключатель.
3. Создать контекст или использовать глобальное состояние (например, `ThemeContext` или Zustand) для управления темой на всех страницах. Если контекст уже есть — использовать его.
4. В корневом компоненте (например, `App.js`) обернуть приложение в провайдер темы и применять класс на `<html>`.
5. Добавить CSS-переменные для тёмной темы в глобальный стиль (`index.css` или `App.css`).
6. Обеспечить плавный переход (transition) цветов при смене темы.
7. Сохранять выбор в `localStorage`.

### Примерная структура кода (для понимания)

**ThemeContext.js**:
```javascript
import React, { createContext, useState, useEffect } from 'react';

export const ThemeContext = createContext();

export const ThemeProvider = ({ children }) => {
  const [theme, setTheme] = useState(() => localStorage.getItem('theme') || 'light');

  useEffect(() => {
    document.documentElement.setAttribute('data-theme', theme);
    localStorage.setItem('theme', theme);
  }, [theme]);

  const toggleTheme = () => {
    setTheme(prev => (prev === 'light' ? 'dark' : 'light'));
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
};
В компоненте шапки:

jsx
import { ThemeContext } from '../context/ThemeContext';

function Header() {
  const { theme, toggleTheme } = useContext(ThemeContext);
  return (
    <button onClick={toggleTheme}>
      {theme === 'light' ? '🌙' : '☀️'}
    </button>
  );
}
CSS (в глобальном файле):

css
:root {
  --bg-color: #ffffff;
  --text-color: #000000;
  --card-bg: #f5f5f5;
  --border-color: #ddd;
}

[data-theme="dark"] {
  --bg-color: #121212;
  --text-color: #e0e0e0;
  --card-bg: #2d2d3f;
  --border-color: #444;
}

body {
  background-color: var(--bg-color);
  color: var(--text-color);
  transition: background-color 0.3s, color 0.3s;
}
Что не нужно делать
Не менять бизнес-логику (генерация карточек, оплата, админка).

Не удалять существующие стили (только добавить поддержку тёмной темы).

Не использовать внешние библиотеки (типа styled-components), если они не используются в проекте.

Дополнительно (по желанию)
Добавить плавную анимацию при переключении (например, fade).

Если в проекте используется Material-UI или другая библиотека — адаптировать тему через их механизмы.

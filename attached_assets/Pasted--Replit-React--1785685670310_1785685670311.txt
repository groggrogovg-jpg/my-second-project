### Задача

Настроить отправку целей в Яндекс.Метрику при успешной оплате пакетов карточек и звёзд.

### Что нужно сделать

1. Найти в коде место, где обрабатывается успешная оплата через ЮMoney:
   - Скорее всего, это компонент страницы возврата после оплаты (`/payment-success`, `/result`).
   - Или функция-обработчик ответа от сервера после подтверждения платежа.

2. В этом месте после успешного начисления карточек/звёзд добавить вызовы `window.ym()` с идентификаторами целей в зависимости от типа и названия пакета:

   **Для пакетов карточек:**
   ```javascript
   if (packageType === 'cards') {
     if (packageName === '5 карточек') {
       window.ym(111247868, 'reachGoal', 'pay_pack_5');
     } else if (packageName === '10 карточек') {
       window.ym(111247868, 'reachGoal', 'pay_pack_10');
     } else if (packageName === '50 карточек') {
       window.ym(111247868, 'reachGoal', 'pay_pack_50');
     } else if (packageName === '100 карточек') {
       window.ym(111247868, 'reachGoal', 'pay_pack_100');
     }
   }
Для покупки звёзд:

javascript
if (packageType === 'stars') {
  if (packageName === '10 звёзд') {
    window.ym(111247868, 'reachGoal', 'pay_stars_10');
  } else if (packageName === '50 звёзд') {
    window.ym(111247868, 'reachGoal', 'pay_stars_50');
  } else if (packageName === '100 звёзд') {
    window.ym(111247868, 'reachGoal', 'pay_stars_100');
  } else if (packageName === '250 звёзд') {
    window.ym(111247868, 'reachGoal', 'pay_stars_250');
  }
}
Если названия пакетов в вашем коде отличаются — адаптируй под них.

Убедиться, что:

Вызов window.ym() происходит строго один раз за успешный платёж.

Есть проверка: if (typeof window.ym === 'function') { ... }, чтобы избежать ошибок, если Метрика ещё не загружена.

Событие отправляется только при реальной успешной оплате, а не при ошибке или повторном заходе на страницу.

Если в проекте есть несколько мест, где обрабатывается оплата (например, отдельные обработчики для карточек и звёзд), проверь, чтобы для каждого типа были свои вызовы.

После добавления кода, для проверки можно в консоли браузера выполнить тестовый вызов:

javascript
ym(111247868, 'reachGoal', 'pay_pack_5');
Должен вернуться ответ ok.

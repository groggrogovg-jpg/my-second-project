Ты — ИИ-помощник по разработке на Replit. Наше React-приложение — КардоМатик. В нём уже есть система звёзд для оплаты инструментов редактирования (списание работает). Теперь нужно реализовать функциональность **покупки звёзд** пользователями через ЮMoney.

### Задача

Разработать полный цикл покупки звёзд: от отображения предложений на фронтенде до начисления звёзд на баланс после успешной оплаты.

---

#### 1. Данные о пакетах звёзд

Создать массив пакетов (или хранить в базе) со следующими параметрами:
- `id` — уникальный идентификатор (например, `stars_10`, `stars_50`, `stars_100`, `stars_250`)
- `stars` — количество звёзд
- `price` — цена в рублях
- `description` — описание (например, «10 звёзд для редактирования»)

Пример пакетов:
| id        | stars | price |
|-----------|-------|-------|
| stars_10  | 10    | 100   |
| stars_50  | 50    | 400   |
| stars_100 | 100   | 700   |
| stars_250 | 250   | 1500  |

Эти данные можно хранить в коде (константа) или в БД — выбери удобный способ.

---

#### 2. Фронтенд: отображение пакетов

На странице `/pricing` (или на отдельной вкладке) добавить блок «Пополнить звёзды». Он должен располагаться **ниже** существующих пакетов карточек. Для каждого пакета отобразить карточку с:
- Количеством звёзд (крупно)
- Ценой
- Кнопкой «Купить»

При клике на кнопку запускается процесс оплаты (см. пункт 3). Если пользователь не авторизован — перенаправить на страницу входа или показать модальное окно.

---

#### 3. Логика оплаты через ЮMoney

Использовать уже существующий в приложении механизм оплаты (скорее всего, это компонент, который создаёт платёж и перенаправляет на страницу ЮMoney). Для звёзд нужно:
- При нажатии «Купить» отправить запрос на сервер для создания платежа.
- В запросе передать `packageId` (например, `stars_10`), `userId` (из сессии) и сумму.
- Сервер должен сгенерировать ссылку на оплату через ЮMoney (или использовать готовый SDK) и вернуть её клиенту.
- Перенаправить пользователя на страницу ЮMoney.
- После успешной оплаты ЮMoney перенаправит пользователя на `return_url` (например, `/payment-success?packageId=stars_10`).

---

#### 4. Обработка успешной оплаты (бэкенд)

На сервере должен быть эндпоинт, который обрабатывает подтверждение от ЮMoney (обычно это webhook или проверка статуса платежа по `paymentId`). При успешном платеже:
- Извлечь `packageId` из метаданных платежа.
- Найти пользователя по `userId` (из сессии или из данных платежа).
- Увеличить поле `stars` в таблице пользователей на количество, соответствующее `packageId`.
- Записать транзакцию в таблицу `transactions` (или аналогичную) с типом `stars_purchase`, суммой, количеством звёзд, датой и статусом `success`.
- Если пользователь не найден — обработать ошибку (логировать, но не начислять звёзды).

---

#### 5. Обновление баланса на фронтенде

После успешной оплаты и начисления звёзд:
- Обновить глобальное состояние (например, через контекст или Redux) с новым значением `stars`.
- Отобразить сообщение об успешном пополнении.
- Если у пользователя отображается баланс в шапке или на странице профиля — он должен обновиться автоматически.

---

#### 6. Обработка ошибок и отмена оплаты

- Если пользователь отменил оплату или произошла ошибка — показать соответствующее уведомление.
- Звёзды не начисляются.
- В базе данных создать запись о неудачной транзакции для аналитики.

---

#### 7. Технические требования

- Все изменения должны быть обратно совместимы с существующей логикой оплаты карточек.
- Не нарушать работу других разделов.
- Код должен быть чистым, с комментариями на русском (или английском) по ключевым моментам.
- Использовать существующие модули для работы с ЮMoney (не создавать новые с нуля, а расширять).
- Если база данных не имеет поля `stars` в таблице пользователей — добавить его (тип integer, по умолчанию 0).

---

### Что не нужно делать

- Не менять логику списания звёзд (она уже работает).
- Не изменять существующие пакеты карточек.
- Не трогать админку, авторизацию, генерацию карточек и другие модули, не связанные с оплатой звёзд.

---

### Ожидаемый результат

- Пользователь видит на странице тарифов блок покупки звёзд.
- Может выбрать пакет и оплатить через ЮMoney.
- После оплаты баланс звёзд увеличивается на купленное количество.
- Интерфейс отображает обновлённый баланс.

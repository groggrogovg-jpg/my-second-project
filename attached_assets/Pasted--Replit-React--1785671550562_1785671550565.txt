Ты — ИИ-помощник по разработке на Replit. Наше React-приложение — КардоМатик. В нём уже есть админ-панель (раздел /admin), где администраторы могут управлять пользователями и просматривать платежи. Теперь нужно добавить в админку функционал ручного пополнения звёзд для любого пользователя.

### Задача

Добавить в интерфейс админ-панели возможность начислять звёзды выбранному пользователю на 5, 10 или 1 звезду.

---

#### 1. Где разместить функционал

- В админ-панели есть страница со списком пользователей (скорее всего, /admin/users). На ней нужно добавить для каждого пользователя либо отдельную кнопку «Пополнить звёзды», либо вынести эту функцию в отдельную вкладку «Управление звёздами».
- Предлагаю добавить кнопку «Пополнить звёзды» рядом с каждым пользователем в таблице (или в строке), которая открывает небольшое модальное окно с выбором количества (1, 5, 10) и кнопкой подтверждения.

Если список пользователей ещё не реализован — его нужно создать. Но скорее всего, он есть.

#### 2. Интерфейс (фронтенд)

- На странице списка пользователей добавить колонку с действиями и кнопку «➕ Звёзды».
- При клике открывается модальное окно или выпадающий блок с:
  - Именем/email пользователя (чтобы админ видел, кому начисляет)
  - Тремя кнопками-пресетами: «+1», «+5», «+10» (или числовое поле ввода, но по заданию нужно именно на 5, 10 и по одной — так что лучше три кнопки)
  - Кнопкой «Пополнить» для подтверждения
- После успешного пополнения показывать уведомление (тост) и обновлять баланс в строке пользователя (если баланс отображается).

#### 3. Бэкенд (API)

- Создать (или расширить существующий) эндпоинт для административного пополнения, например:
  - POST /api/admin/add-stars
  - Принимает: `userId` (или email) и `amount` (число, 1, 5 или 10)
  - Проверяет, что текущий пользователь — администратор (по роли или специальному флагу в сессии).
  - Находит пользователя по ID.
  - Обновляет поле `stars` в таблице users: `UPDATE users SET stars = stars + $1 WHERE id = $2`
  - Записывает транзакцию в таблицу `transactions` (или `stars_log`) с типом `admin_added`, суммой (количество звёзд), датой и ID администратора (опционально).
  - Возвращает обновлённый баланс пользователя.

- Если таблицы транзакций нет — создать её (поля: id, user_id, amount, type, created_at, admin_id). Либо использовать существующую, если она есть.

#### 4. Безопасность

- Только пользователи с ролью `admin` (или флагом `is_admin = true`) должны иметь доступ к этому эндпоинту и кнопке в админке.
- Проверка должна быть как на фронтенде (скрытие кнопки для не-админов), так и на бэкенде (чтобы никто не мог подделать запрос).

#### 5. Обратная связь

- После успешного пополнения показать сообщение: «Пользователю {email} начислено {amount} звёзд».
- В случае ошибки (пользователь не найден, недостаточно прав и т.д.) — показать понятное сообщение.

#### 6. Требования к коду

- Использовать существующие компоненты (модалки, тосты), если они уже есть в проекте. Если нет — создать простые.
- Код должен быть расширяемым (например, легко добавить другие суммы позже).
- Не изменять логику работы звёзд в других частях приложения (генерация карточек, списание и т.д.)

#### Что не нужно делать

- Не менять пользовательскую часть (не добавлять кнопки пополнения на страницы пользователей).
- Не трогать существующие платежи через ЮMoney — это отдельная логика.

### Ожидаемый результат

- В админ-панели администратор может выбрать пользователя и начислить ему 1, 5 или 10 звёзд.
- Баланс пользователя обновляется мгновенно.
- Транзакция записывается в лог (для отчётности).

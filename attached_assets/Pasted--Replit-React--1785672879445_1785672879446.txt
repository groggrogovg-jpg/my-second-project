Ты — ИИ-помощник по разработке на Replit. Наше React-приложение — КардоМатик. В нём уже есть редактор изображений с функциями удаления фона, заливки, ластика и шаблонов фонов. Теперь нужно добавить новый инструмент: **замена фона через ИИ-модель** с использованием платформы **Polza**.

### Задача

Добавить в редактор изображений кнопку/вкладку «✨ ИИ-фон» (или «ИИ-замена фона»), которая позволяет пользователю заменить фон товара на сгенерированный по текстовому описанию.

---

#### 1. Использование Polza

- В приложении уже настроена интеграция с Polza для вызова моделей (или будет добавлена). Polza предоставляет API для замены фона: на вход подаётся изображение и текстовый промпт, на выходе — новое изображение с изменённым фоном.
- Агенту не нужно заботиться о выборе конкретной модели — Polza уже содержит подходящую модель (например, для редактирования изображений по промпту).
- Логика вызова: клиент отправляет запрос на серверный эндпоинт `/api/polza/change-background`, который принимает изображение (файл или base64) и строку-описание фона, вызывает Polza и возвращает URL или base64 результата.
- Если серверный эндпоинт ещё не создан — его нужно создать. Использовать существующие в проекте утилиты для работы с Polza (если они есть) или создать простой прокси.

---

#### 2. Интерфейс (фронтенд)

- В панели инструментов редактора добавить новую кнопку «✨ ИИ-фон».
- При клике открывается модальное окно или панель с:
  - **Текстовым полем** для ввода описания желаемого фона (placeholder: «Например: уютная комната с камином, студийный белый фон, лесная поляна...»).
  - **Кнопкой «Сгенерировать»**.
  - Индикатором загрузки (spinner) во время генерации.
  - Превью текущего изображения и результата после генерации.
- После получения результата пользователь может:
  - **Применить** — заменить текущее изображение в редакторе на новое.
  - **Отменить** — закрыть модалку без изменений.
  - **Сгенерировать заново** с другим промптом.

---

#### 3. Логика вызова модели через Polza

- При нажатии «Сгенерировать»:
  1. Проверить, что пользователь авторизован и имеет достаточно звёзд (см. пункт 4).
  2. Отправить текущее изображение (как файл или base64) и промпт на серверный эндпоинт `/api/polza/change-background`.
  3. Сервер получает запрос, вызывает Polza (используя соответствующий API-ключ, который уже хранится в переменных окружения), ждёт ответа и возвращает результат (ссылка на сгенерированное изображение или base64).
  4. Клиент получает результат и отображает его в модалке.
- Если Polza возвращает ошибку — показать понятное сообщение пользователю.

---

#### 4. Списание звёзд

- Каждый вызов ИИ-генерации фона должен списывать **звёзды** с баланса пользователя (например, 3–5 звёзд за одну генерацию). Количество звёзд можно настроить в конфиге или задать константой.
- Использовать существующую логику списания звёзд (которая уже есть в приложении для других инструментов).
- Перед вызовом модели проверить, что у пользователя достаточно звёзд. Если нет — показать сообщение и предложить пополнить баланс.
- После успешной генерации — списать звёзды и обновить отображение баланса в интерфейсе.

---

#### 5. Интеграция с существующим редактором

- Новый инструмент должен работать **поверх текущего изображения** в редакторе (как и другие функции — удаление фона, заливка и т.д.).
- После применения результата — обновить холст/состояние редактора новым изображением.
- Не нарушать работу других инструментов (ластик, шаблоны и т.д.).

---

#### 6. Обработка ошибок

- Если Polza вернул ошибку — показать понятное сообщение пользователю.
- Если генерация заняла слишком много времени — добавить таймаут (например, 30 секунд) и сообщить об ошибке.
- Если пользователь ввёл слишком короткий или неинформативный промпт — предложить уточнить.

---

#### 7. Технические требования

- Использовать существующие компоненты (модалки, кнопки, тосты) — не создавать новые с нуля, если они уже есть.
- Если серверный эндпоинт ещё не реализован — создать его в папке `api/` (например, `api/polza/change-background.js`).
- В эндпоинте использовать переменную окружения `POLZA_API_KEY` (или аналогичную) для авторизации. Если переменной нет — создать `.env` с примером.
- Код должен быть расширяемым — чтобы позже можно было легко заменить модель или провайдера, не меняя фронтенд.

---

### Что не нужно делать

- Не менять логику генерации карточек (Nano Banana 2 / Pro).
- Не трогать админку, платежи через ЮMoney, авторизацию.
- Не изменять существующие инструменты редактора (удаление фона, заливка, ластик, шаблоны).

---

### Ожидаемый результат

- В редакторе изображений появилась кнопка «✨ ИИ-фон».
- При клике открывается модалка с полем для промпта и кнопкой генерации.
- После генерации изображение с новым фоном отображается в редакторе.
- За каждую генерацию списываются звёзды (если реализовано).
- Ошибки обрабатываются и показываются пользователю.

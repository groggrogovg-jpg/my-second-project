Ты работаешь над проектом Neiro Card AI (KardoMatik) на платформе Replit. Требуется добавить функционал генерации SEO-оптимизированного текста для карточки товара и защитить его от копирования в пробном режиме.

### 1. Генерация SEO-текста после создания карточки

**Требуемое поведение:**
- Сразу после успешной генерации карточки (или при её сохранении) система должна автоматически генерировать SEO-текст для этой карточки.
- Текст должен включать:
  - **Описание товара** (2–3 предложения, основанные на названии и преимуществах).
  - **Ключевые слова** (5–10 слов или фраз, релевантных для маркетплейсов).
  - **Заголовок для маркетплейса** (до 60 символов).
  - **Краткий список преимуществ** (уже есть, но можно дополнить).
- Генерация выполняется через AI API (например, OpenRouter, Polza или другой LLM), используя данные, введённые пользователем (название товара, цена, преимущества, промпт фона и т.д.).
- Если AI API недоступно или ключ не задан, использовать шаблонный текст-заглушку с уведомлением.

**Техническая реализация:**
- Создать новую функцию на бэкенде (например, `generateSEOText(data)`), которая отправляет запрос к LLM и возвращает структурированный JSON.
- Сохранять полученный SEO-текст в БД вместе с карточкой (в таблицу `cards` добавить поле `seo_text` типа JSON или TEXT).
- На фронтенде после генерации карточки отображать этот текст в отдельном блоке (например, под карточкой или в правой панели редактора).
- Блок должен быть свёрнут по умолчанию с заголовком «SEO-оптимизация для маркетплейсов» и кнопкой раскрытия.

### 2. Защита от копирования SEO-текста в пробном периоде

**Требуемое поведение:**
- Для пользователей, у которых нет активного баланса (`nano2_balance = 0` и `pro_balance = 0`) и для неавторизованных, SEO-текст должен быть **защищён от копирования**.
- Способы защиты:
  - **Блокировка выделения текста** (CSS `user-select: none`).
  - **Блокировка контекстного меню** (JavaScript `onContextMenu`).
  - **Наложение полупрозрачного слоя** (overlay) поверх текста, чтобы его нельзя было скопировать через DevTools (но это сложнее, можно просто ограничить выделение).
  - **Показывать только часть текста** (например, первые 30 символов) с предложением купить пакет для полного доступа.
- Для авторизованных пользователей с положительным балансом текст должен быть полностью доступен для копирования (без ограничений).
- В дополнение, можно добавить водяной знак на сам SEO-текст (например, фон с надписью «Демо-версия»), но это не обязательно.

**Где менять:**
- Найти компонент, который отображает SEO-текст (допустим, `SEOTextBlock.jsx`).
- Добавить проверку:
  ```javascript
  const canCopy = user && (user.nano2_balance > 0 || user.pro_balance > 0);
Если canCopy === false, применить CSS-стили userSelect: 'none', отключить контекстное меню, и возможно добавить наложение (overlay) с текстом «Доступно после покупки пакета».

Если canCopy === true, отображать текст без ограничений и добавить кнопку «Копировать текст» (или просто позволить выделение).

3. Отображение SEO-текста в интерфейсе
Где показывать:

В редакторе, после завершения генерации карточки (в правой панели или под холстом).

В отдельном блоке с заголовком «SEO-текст для маркетплейсов».

Если пользователь не может копировать, блок содержит предупреждение (например, «Этот текст защищён от копирования в пробной версии. Купите пакет, чтобы скопировать»).

4. Проверка после внесения изменений
Сгенерируй карточку (в пробном режиме) → должен появиться SEO-текст, но выделение и копирование запрещены.

Зарегистрируйся и купи пакет → сгенерируй новую карточку → текст должен копироваться.

Проверь, что старые карточки (если есть) получают SEO-текст при их повторном открытии или при генерации новой.

Общие требования
Не ломать существующую логику генерации, балансов, пробных попыток и водяного знака.

Если ключ API для LLM отсутствует, использовать заглушку и логировать предупреждение в консоль.

Все изменения должны быть совместимы с текущей архитектурой (если нужно добавить поле в БД, выполнить миграцию).

После выполнения покажи список изменённых файлов и инструкции по тестированию.

Если структура проекта отличается, адаптируй изменения под текущую архитектуру.

- После генерации карточки будет появляться SEO-текст (описание, ключевые слова, заголовок).

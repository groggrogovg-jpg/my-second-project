Ты — ИИ-помощник по разработке на Replit. Наше приложение — КардоМатик. На странице /faq (или /support) есть блок «Часто задаваемые вопросы» с вложенными списками вопросов (как на скриншоте). Сейчас все подвопросы видны сразу. Нужно сделать так, чтобы подвопросы были скрыты по умолчанию и появлялись только при клике на родительский вопрос (аккордеон). При этом чат-бот, который парсит эту страницу, должен продолжать видеть все вопросы и ответы (скрытие должно быть только визуальным, через CSS, но элементы должны оставаться в DOM).

### Задача

Реализовать аккордеон для страницы FAQ, используя **только CSS** (без JavaScript) с помощью скрытых чекбоксов и псевдокласса `:checked`. Это позволит сохранить доступность и не менять структуру HTML для поисковых систем и парсера.

### Что нужно сделать

1. Найти компонент или файл, отвечающий за рендеринг страницы FAQ (скорее всего, это `pages/FAQ.js`, `components/FAQ.js` или статический HTML).
2. Изменить разметку блока FAQ следующим образом:
   - Каждый **родительский вопрос** (категория) обернуть в `<label>` с атрибутом `for`, связанным с уникальным ID чекбокса.
   - Добавить **скрытый чекбокс** `<input type="checkbox" id="faq-1">` перед каждым родительским вопросом.
   - Вложенные подвопросы (ответы) обернуть в контейнер (например, `<div class="faq-answer">`).
   - Использовать CSS-правила: по умолчанию контейнер с ответами скрыт (`display: none`), при `:checked` родительского чекбокса — показывать (`display: block`).
3. Сохранить все существующие классы и стили, чтобы не нарушить дизайн.
4. Убедиться, что чат-бот (который парсит страницу) по-прежнему видит все вопросы и ответы, так как они остаются в DOM.
5. Добавить плавную анимацию появления/исчезновения (например, `max-height` и `opacity`).

### Пример структуры (до и после)

**До (плоский список):**
```html
<ul>
  <li><strong>Виртуальная примерка одежды</strong>
    <ul>
      <li>Что такое виртуальная примерка в КардоМатик?</li>
      <li>Какие вещи можно примерять на модели?</li>
    </ul>
  </li>
</ul>
После (аккордеон):

html
<ul>
  <li>
    <input type="checkbox" id="faq-virtual" class="faq-toggle" hidden>
    <label for="faq-virtual" class="faq-question">Виртуальная примерка одежды</label>
    <div class="faq-answer">
      <ul>
        <li>Что такое виртуальная примерка в КардоМатик?</li>
        <li>Какие вещи можно примерять на модели?</li>
      </ul>
    </div>
  </li>
</ul>
CSS:

css
.faq-answer {
  max-height: 0;
  overflow: hidden;
  transition: max-height 0.3s ease;
}
.faq-toggle:checked + .faq-question + .faq-answer {
  max-height: 500px; /* или auto, но тогда анимация не сработает */
}
/* или использование display: none/block с анимацией через max-height */
Альтернативный вариант (если менять разметку сложно)
Если структура генерируется динамически (React-компонент), можно добавить логику состояния (useState) для каждого вопроса, но тогда потребуется JavaScript. Однако по условию "не меняя код" подразумевается минимальное вмешательство. Поэтому я рекомендую CSS-подход с чекбоксами, который не требует переписывания логики и подходит для статической или серверной генерации.

Что не нужно делать
Не удалять вложенные списки из DOM.

Не использовать JavaScript для управления видимостью (чтобы не влиять на парсинг).

Не менять логику чат-бота (он должен видеть всё).

Дополнительно
Добавить иконку (например, стрелку) для визуального указания, что вопрос раскрывается.

Обеспечить доступность: использовать правильные ARIA-атрибуты (если возможно).

Ты — ИИ-помощник по разработке на Replit. Наше приложение — КардоМатик.

### Задача

Создать чат-виджет на сайте, который отвечает на вопросы пользователей БЕЗ использования ИИ. Бот должен работать на основе заранее подготовленной базы вопросов и ответов (FAQ), составленной из информации, опубликованной на сайте.

### Что нужно сделать

#### 1. Создать базу FAQ

Создать файл или модуль с массивом объектов, содержащих:
- `keywords` — массив ключевых слов (на русском), по которым бот будет искать вопрос
- `question` — пример вопроса (для отображения в интерфейсе)
- `answer` — готовый ответ (текст, можно с форматированием)

Наполнить базу следующими вопросами:

   Ключевые слова: ['цена', 'стоимость', 'рубль', 'карточка']
   Ответ: «Цена зависит от выбранного пакета. В пакете «5 карточек» одна карточка стоит около 80 ₽, в пакете «100 карточек» — около 55 ₽. Точные цены смотрите на странице Тарифы.»

#### 2. Создать компонент чат-виджета

- Плавающая иконка в правом нижнем углу экрана.
- При клике — открывается окно чата (модальное или выдвигающееся).
- В окне — поле ввода текста и кнопка отправки.
- При отправке сообщения:
  - Бот выделяет ключевые слова из вопроса пользователя.
  - Ищет наиболее подходящий ответ по совпадению ключевых слов.
  - Если совпадение найдено — выводит соответствующий ответ.
  - Если нет — выводит сообщение: «К сожалению, я не нашёл ответа. Пожалуйста, напишите в поддержку через Telegram (ссылка)».

#### 3. Логика поиска (без ИИ)

- Использовать простой алгоритм: разбить вопрос пользователя на слова, привести к нижнему регистру, убрать стоп-слова (как, где, когда, это и т.д.), затем искать совпадения с ключевыми словами из базы.
- Можно использовать библиотеку `fuse.js` для нечёткого поиска (но она не обязательна, можно и обычным `includes`). Если ставите `fuse.js`, установите её через npm.
- Для начала подойдёт простой цикл по базе с подсчётом совпадений.

#### 4. Интеграция в приложение

- Компонент чат-виджета добавить на все страницы (в корневой компонент App.js).
- База FAQ может храниться в отдельном файле (например, `data/faq.js`), чтобы её было легко редактировать.

#### 5. Дизайн

- Виджет должен быть адаптивным (мобильная версия тоже).
- Дизайн в стиле вашего приложения (цвета, шрифты).
- Окно чата должно показывать историю сообщений (пользователь → бот).

#### 6. Дополнительно (опционально)

- Добавить кнопку «Написать в поддержку» в чате (переход на Telegram или на страницу контактов).

### Что не нужно делать

- Не использовать API OpenAI или другие ИИ-сервисы.
- Не менять существующие разделы (генерация карточек, админка, оплата).

### Ожидаемый результат

- На сайте появился плавающий чат-виджет.
- Бот отвечает на типовые вопросы на основе подготовленной базы.
- Если ответ не найден — предлагает обратиться в поддержку.

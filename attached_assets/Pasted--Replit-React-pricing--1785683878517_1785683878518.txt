Ты — ИИ-помощник по разработке на Replit. Наше React-приложение — КардоМатик. На странице /pricing (или /tariffs) есть блок «Пополнить звёзды» с карточками покупки звёзд (10, 50, 100, 250). Сейчас при покупке звёзд нет обязательного чекбокса с соглашением, как для пакетов карточек.

### Задача

Добавить для каждого блока покупки звёзд (или один общий для всех) чекбокс с текстом:

«Принимаю Соглашение о подписке и Политику конфиденциальности»

По аналогии с чекбоксами, которые уже есть для пакетов карточек на скриншоте.

### Что нужно сделать

1. Найти компонент, отвечающий за рендеринг блока «Пополнить звёзды» (скорее всего, это `StarsPurchase.js`, `Pricing.js` или аналогичный).

2. В этом компоненте добавить чекбокс:
   - Разместить чекбокс **под каждой карточкой** с ценой и кнопкой «Купить» (как в пакетах карточек).
   - Или разместить **один общий чекбокс под всеми карточками звёзд** (но лучше под каждой — для единообразия).

3. Текст чекбокса:
   «Принимаю Соглашение о подписке и Политику конфиденциальности»

4. Ссылки:
   - Ссылка «Соглашение о подписке» должна вести на `/legal/subscription-agreement`
   - Ссылка «Политику конфиденциальности» должна вести на `/privacy-policy`

5. Логика:
   - Кнопка «Купить» должна быть **неактивной (disabled)**, пока чекбокс не отмечен.
   - После отметки чекбокса — кнопка становится активной.
   - При клике на текст чекбокса (а не только на квадратик) — тоже должен ставиться флажок.

6. Стилизация:
   - Использовать такие же стили, как для чекбоксов в пакетах карточек (цвет, размер, отступы).
   - Чекбокс должен быть адаптивным (на мобильных устройствах тоже корректно отображаться).

### Что не нужно делать

- Не менять логику покупки звёзд (она уже работает).
- Не трогать другие разделы страницы (пакеты карточек, шапку, футер).
- Не изменять дизайн карточек со звёздами (только добавить чекбокс под ними).

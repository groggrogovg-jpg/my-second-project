Мне нужно реализовать систему восстановления пароля "Забыли пароль?" для моего веб-приложения kardomatik.ru. 

Контекст инфраструктуры:
1. Проект хостится на Replit.
2. Для отправки писем используется SMTP сервер Beget (smtp.beget.com).
3. У меня есть ДВА почтовых ящика на домене kardomatik.ru:
   - noreply@kardomatik.ru — ТОЛЬКО для системных уведомлений (сброс пароля).
   - support@kardomatik.ru — для ручной поддержки (в этом коде НЕ использовать).

Технические требования к реализации:
1. Безопасность: 
   - НИКОГДА не отправлять новый пароль в письме.
   - Генерировать криптографически стойкий токен (UUID или secure random).
   - Токен должен иметь срок жизни 1 час.
   - Токен можно использовать только ОДИН раз (после использования помечать как использованный или удалять).

2. База данных:
   - Создай модель/таблицу `password_reset_tokens` с полями: id, user_id, token_hash (хеш токена!), expires_at, used (boolean).
   - В БД хранить ХЕШ токена, а не сам токен (для безопасности).

3. Endpoints:
   - POST /api/auth/forgot-password: принимает email, генерирует токен, сохраняет хеш в БД, отправляет письмо через SMTP Beget.
   - GET /reset-password?token=...: страница с формой нового пароля (валидирует токен при загрузке).
   - POST /api/auth/reset-password: принимает token + new_password, проверяет токен, обновляет пароль пользователя, помечает токен как использованный.

4. Отправка письма (SMTP Beget):
   - Используй переменные окружения из Secrets: SMTP_HOST, SMTP_PORT, SMTP_USER (noreply@kardomatik.ru), SMTP_PASS.
   - Письмо должно быть на русском языке, с понятной инструкцией и кнопкой/ссылкой.
   - Обработай ошибки SMTP gracefully (не падай, если письмо не ушло, но логируй ошибку).

5. Rate Limiting:
   - Ограничь запросы на /forgot-password: не чаще 1 раза в 5 минут на один email (чтобы не спамить пользователя и не нагружать SMTP).

6. Код:
   - Напиши полный, рабочий код всех необходимых файлов.
   - Добавь комментарии на русском языке.
   - Убедись, что пароли пользователей хешируются (bcrypt/argon2) перед сохранением.

Язык проекта: [УКАЖИТЕ ВАШ ЯЗЫК: Python Flask / Node.js Express / Django и т.д.]
База данных: [УКАЖИТЕ ВАШУ БД: SQLite / PostgreSQL / MongoDB]

Начни с создания модели токенов, затем endpoint забыл пароль, затем функцию отправки SMTP, и наконец страницу сброса.

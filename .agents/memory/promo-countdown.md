---
name: Promotional countdown
description: Правило для временных акций на странице генерации
---

Таймер акции для конкретного пользователя хранится в localStorage с ключом, привязанным к ID аккаунта, и запускается при появлении условия акции, а не при каждом открытии страницы.

**Why:** Пользователь должен видеть стабильный остаток времени после обновления страницы, а разные аккаунты в одном браузере не должны делить один таймер.

**How to apply:** Для новых клиентских акций сохранять timestamp окончания, а не только оставшееся число секунд; после истечения показывать 00:00:00.

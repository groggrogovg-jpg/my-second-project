---
name: Editor paid actions
description: Правило подтверждения и списания звёзд для платных инструментов редактора изображений
---

Платные действия в редакторе должны запрашивать подтверждение до начала операции, а сервер должен списывать звёзды только после успешного результата. При ошибке результат и баланс должны оставаться без изменений. Баланс редактора должен приходить из `/api/auth/me`, а списание — атомарно через PostgreSQL `UPDATE ... WHERE stars_balance >= amount`.

**Why:** локальная операция или внешний AI-запрос могут завершиться ошибкой после подтверждения; предварительное списание создаёт некорректное уменьшение баланса.

**How to apply:** новые платные инструменты редактора подключать к существующему балансу звёзд через серверную проверку авторизации, достаточности средств и финальное списание после успеха. Пакеты Nano2/Pro начисляют звёзды по схеме 5/10/50/100; профиль и тарифы отображают этот баланс/бонус. Перегенерация текста также требует и списывает 1 звезду.

Для смены фона стоимость зависит от выбранной модели: Nano Banana 2 — 1 ⭐, Grok Imagine — 2 ⭐, GPT Image 1.5 — 3 ⭐. Каталог моделей общий для модалки и backend, а списание выполняется после успешного ответа Polza.

**Why:** Разные модели имеют разную ценность и стоимость; цена только на клиенте позволила бы обойти баланс, а предварительное списание нарушило бы гарантию сохранения баланса при ошибке генерации.

**How to apply:** Новые модели фонового редактирования добавлять в `BACKGROUND_MODELS` и серверную карту Polza одновременно; сервер должен вычислять стоимость по проверенному ID модели, а не доверять присланной цене.

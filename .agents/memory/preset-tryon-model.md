name: Preset virtual try-on model
description: Правило работы вкладки примерки с администраторской моделью и fallback-оверлеем
---

Вкладка «Примерка» использует одну предустановленную модель из статического ассета; пользователь загружает только одежду. Endpoint сохраняет совместимость с ручным `person`, но при его отсутствии подставляет эту модель и при сбое AI создаёт локальный оверлей первой вещи.

**Why:** пользовательский сценарий должен начинаться сразу с готовой модели, а примерка должна оставаться работоспособной без доступного AI.

**How to apply:** не возвращать обязательный upload модели в UI; сохранять `trial_tryon_used`, серверный watermark и ограничение скачивания для пробного результата. Новый платный баланс разблокирует скачивание в клиенте.

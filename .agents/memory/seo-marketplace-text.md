---
name: Marketplace SEO text
description: Правило формирования, хранения и ограничения SEO-текста для карточек товаров
---

SEO-текст карточки строится из уже полученного анализа товара и сохраняется вместе с объектом генерации; отдельный второй AI-запрос для SEO не нужен. Если AI-анализ недоступен, используется явно помеченный шаблонный вариант.

**Why:** это сохраняет расход AI-запросов предсказуемым и позволяет старым генерациям работать даже без нового отдельного SEO-поля.

**How to apply:** при изменении структуры анализа обновлять преобразование SEO и fallback одновременно; пробный результат может показывать только защищённое сокращённое превью, а положительный платный баланс открывает просмотр и копирование.

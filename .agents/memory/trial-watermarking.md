# Trial content protection

## Правило

Для пользователей в trial-режиме:
1. Сервер скачивает изображение от Polza.ai и накладывает вшитый водяной знак (сетка диагонального текста через `sharp` + SVG).
2. Водяной знак применяется при генерации, редактировании фона и примерке.
3. Результат хранится в `resultImageUrl` как `data:image/png;base64,...`, а не как оригинальный URL Polza.ai.
4. Клиент показывает trial-изображение через `<canvas>`, блокирует правый клик, перетаскивание и Ctrl+S.

Для оплаченных генераций водяной знак не накладывается, URL остаётся оригинальным, скачивание разрешено.

**Why:** Если для trial отдавать оригинальный URL, пользователь может сохранить чистое изображение через прямой URL, обойдя любой client-side overlay. Data-URL гарантирует, что клиент получает только уже защищённую копию.

**How to apply:** При любой новой точке, где результат генерации отдаётся пользователю (новый endpoint, новая функция редактирования), используй `processResultImage(url, isTrial)` и сохраняй `usedTrial` в записи генерации. Если isTrial — верни data-URL, иначе можно оставить оригинальный URL.
